- Оффлайн-фолбэка для проверки достаточно: «Да, достаточно» (00:53:58).

  мощности нет (00:51:05).
- Зарубежные LLM API «не являются минусом» (00:51:05).
- Локальная модель — не минус, даже плюс, но «не стоит из-за моих слов бежать
  делать всё на локальных моделях» (00:51:05).

  подключению, организаторы создадут свой ключ для проверки (00:52:35).
- Проверка прототипа — запуск Docker у себя, приложенные данные проверяются
  (00:49:47).
- Скачивание из интернета во время проверки допустимо, ограничений для среды
  нет (00:55:37).
- Способ запуска локальной модели, если она используется, любой: LM Studio,
  Ollama, Docker, gguf напрямую (00:52:35).
